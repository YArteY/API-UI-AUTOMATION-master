Supuestos del plan
  • Disponibilidad de 2 a 3 horas por día en días laborables.
  • Sábados como días ligeros y domingos de descanso o recuperación.
  • El 4 y 5 de noviembre quedan como colchón para revisión y entrega.
  • Si hay atraso, el primer recorte es la parametrización (día 11) y el segundo, la cobertura con pytest-cov (día 13). El núcleo (git + API + UI + CI) es intocable.

2API al 100 % (21–23 oct)

DíaFechaTareas claveListo cuando…
